# BoostSSH public pages

Public product, privacy and terms pages for BoostSSH. These pages contain no Android application source, secrets, analytics scripts or user data. Hosted by GitHub Pages at https://x4bnet.github.io/boostssh/.

Preview with `python -m http.server 8766 --bind 127.0.0.1`.

The Android app's minimum supported platform is Android 16 (API 36). Optional backups use Google Drive; the developer does not operate a data collection or synchronization backend.
